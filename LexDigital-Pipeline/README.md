# LexDigital Pipeline

Backend WebSocket para LexDigital UXP Plugin.

## Estructura

LexDigital-Pipeline/
  package.json
  server.js
  config.json
  core/

La carpeta core contiene una copia del src original.
El src original se conserva intacto.

## Instalacion

npm install

## Ejecucion

npm start

Servidor:

ws://127.0.0.1:8765
