# Cliente Adobe UXP - InDesign (LexDigital)

Este directorio contiene los archivos necesarios para cargar el panel de control como un plugin UXP dentro de Adobe InDesign (v17.0+):

- `manifest.json`: Manifiesto de especificación UXP v4 para Adobe InDesign.
- `extraer-indesign.js`: Script cliente para la extracción directa de historias y párrafos desde el DOM de InDesign.
